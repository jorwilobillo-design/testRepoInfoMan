# Sprint 1 Test Plan

Related issue: #7 — Test website
Status: Draft; all tests Not run.

## Objective
Check that the website's main pages, navigation, buttons,
layout, and content work according to the agreed requirements.

## Requirements Before Testing
- Working website URL or instructions to run the project.
- List of pages and expected button/link behavior.
- Approved layout or design reference.
- Test accounts if any pages require login.

## Planned Test Cases

| ID | Test steps | Expected result | Status |
| --- | --- | --- | --- |
| TC-01 | Open each main page using its URL. | Each page loads and displays its expected content. | Not run |
| TC-02 | Click each navigation link. | Each link opens the intended page. | Not run |
| TC-03 | Click each button and compare its behavior with the requirements. | Each button performs its intended action. | Not run |
| TC-04 | Compare page text and images with the supplied content. | Content is correct, readable, and images load. | Not run |
| TC-05 | Compare each page with the approved design. | Layout matches the design without overlapping or clipped content. | Not run |
| TC-06 | Repeat page and navigation checks at desktop and mobile widths. | Content remains usable and navigation remains accessible. | Not run |

## Test Execution Record
For each executed test, record:
- Date and tester.
- Website version, commit, or branch tested.
- Browser and screen size.
- Actual result.
- Passed, Failed, or Blocked.
- Screenshot or bug issue link when applicable.

## Bug Reporting
For each bug, create an issue containing:
- Clear title.
- Page URL and version tested.
- Steps to reproduce.
- Expected result.
- Actual result.
- Screenshot and browser details.
- Impact on the user.

After a fix is available, repeat the failed test and record
whether the problem is resolved.

## Completion Criteria
- Planned tests have been executed.
- Actual results have been recorded.
- Errors found have been reported for fixing.
- Outstanding bugs and blocked tests are disclosed to the team.

## Current Limitations
No tests have been executed under this plan.
Execution requires a working website and the references listed above.
This document does not establish that the website passed testing.
